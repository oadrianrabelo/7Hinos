# Segurança

Encontrou uma falha de segurança no 7Hinos (por exemplo, no controle pelo
celular ou na atualização automática)? **Não abra uma issue pública.**

Use **Security → Report a vulnerability** neste repositório
(<https://github.com/oadrianrabelo/7Hinos/security/advisories/new>). A
mensagem fica visível só para quem mantém o projeto.

Corrigimos na versão mais recente; como o app se atualiza sozinho, as igrejas
recebem a correção sem precisar fazer nada.
